# Simulation and data tools

This folder contains **two immediately executable tools** and one synthetic test fixture.
They are not atomistic simulations and do not claim to predict the battery chemistry.

## 1. Quantity calculator

```bash
python simulation/cell_sizing_calculator.py
```

Example for three symmetric cells:

```bash
python simulation/cell_sizing_calculator.py --cells 3 --mncl2-g 0.7 --mn3o4-mg 100 --naoh-ratio 4
```

The reported Mn3O4 yield is a theoretical maximum based on manganese balance. It is not an observed synthesis yield.

## 2. Cycler-data analysis

Convert the instrument's export to the canonical CSV columns:

- `time_s`: elapsed test time in seconds (monotonic within each cycle/step)
- `cycle`: integer cycle number
- `step`: exactly `charge` or `discharge`
- `voltage_V`: measured cell-terminal voltage
- `current_A`: measured current in amperes

Run:

```bash
python simulation/analyze_cycler_csv.py path/to/cycler.csv \
  --positive-active-mg 5.00 --negative-active-mg 5.00 --out-dir analysis_out
```

Outputs: `cycle_summary.csv` and `summary.json`.

The tool integrates measured current and terminal power using trapezoidal integration. It reports both (a) normalization by total active mass on both electrodes and (b) normalization by mean active mass on one electrode. Do not select a normalization basis until the paper's supporting-information convention and the instrument's mass entry are reconciled.

## 3. Synthetic pipeline test

`demo_synthetic_data.csv` is intentionally fictional and contains a `data_status` column marking every row `SYNTHETIC_TEST_ONLY`. It is solely for testing the script's operation. Never use its outputs in a research result, investor deck or YC application.

```bash
python simulation/analyze_cycler_csv.py simulation/demo_synthetic_data.csv \
  --positive-active-mg 5 --negative-active-mg 5 --out-dir /tmp/r0_demo
```

## 4. Atomistic simulation is not yet ready

Do not launch DFT/MD from a guessed structure. The 2019 paper describes a disordered, hydrated sodium-birnessite phase (nominally Na0.27MnO2·0.63H2O). A suitable CIF/structure must be obtained from supplementary structural data or generated by a documented refinement of the team's XRD data. Only then can a reproducible Quantum ESPRESSO / CP2K / ASE workflow be parameterised. A guessed ordered crystal would answer a different scientific question.

## 5. One-RC + lumped thermal engineering model

The model uses a measured OCV-vs-SOC curve, capacity, ohmic resistance, polarization resistance/capacitance and thermal parameters. The parameter template intentionally contains nulls and will refuse to run until actual measurements are entered.

```bash
python simulation/equivalent_circuit_model.py \
  simulation/rc_model_parameters_template.json path/to/current_profile.csv
```

Current-profile columns: `time_s,current_A,ambient_temperature_C`; positive current means discharge and negative means charge. This model does not simulate Na diffusion, crystal transitions, gas generation, dendrites, side reactions, aging or fire. It is for first-order electrical/thermal system exploration only.

The `rc_model_demo_synthetic_parameters.json` and `current_profile_demo_synthetic.csv` are fictional software-test inputs. Outputs from them are not battery measurements or scientifically predictive results.


## 6. Vehicle moonshot requirement arithmetic

`moonshot_requirements.py` converts assumed vehicle consumption, range and charging time into energy and average terminal charging-power requirements. It is arithmetic only and does not predict a battery's charging acceptance or performance.

```powershell
py -3 simulation/moonshot_requirements.py --consumption-low 15 --consumption-high 20 --range-km 1500 --charge-minutes 5 --cell-whkg 875
```
