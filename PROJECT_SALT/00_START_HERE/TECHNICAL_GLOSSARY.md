# Technical glossary

| Term | Meaning in this package |
|---|---|
| **ASR** | Area-specific resistance (Ω·cm²). Over-potential = current density × ASR. |
| **β''-alumina (BASE)** | Na⁺-conducting ceramic (Na₂O·~5Al₂O₃, Li/Mg-stabilised). Separator and electrolyte in ZEBRA, NAS and the S-cell. |
| **C-rate** | Current relative to capacity: 1C empties the cell in 1 h; 12C in 5 min. |
| **CAM** | Cathode active material. "Wh/kg-CAM" counts only that material. |
| **CC / CV** | Constant current / constant voltage charging phases. |
| **CE** | Coulombic efficiency: charge out ÷ charge in, per cycle. |
| **CCD** | Critical current density: above it, metal plating forms dendrites through a solid electrolyte. |
| **Discharged-state assembly** | Building a metal-chloride cell from NaCl + metal powder. Sodium appears only on first charge. |
| **DFN / SPMe** | Doyle–Fuller–Newman porous-electrode model / single-particle model with electrolyte (PyBaMM). |
| **DFT+U** | Density-functional theory with a Hubbard U correction on localised d-electrons. Here: PBE+U, Quantum ESPRESSO 7.6. |
| **G1–G5** | S-cell R0 pass/kill gates (`params/scell_params.py`). |
| **IT** | Intermediate temperature (~190 °C), versus classic ZEBRA at 270–350 °C. |
| **K4** | Buyer-premium kill test from the earlier decision memo. |
| **LCOS** | Levelised cost of storage: lifetime cost ÷ lifetime energy delivered ($/kWh delivered). |
| **MCS** | Megawatt Charging System connector (≤ 3,000 A × 1,250 V = 3.75 MW). |
| **NaAlCl₄** | Sodium tetrachloroaluminate. Molten secondary electrolyte (mp ≈ 157 °C) carrying Na⁺ inside the cathode. |
| **NFPP** | Na₄Fe₃(PO₄)₂P₂O₇: low-cost Na-ion cathode. |
| **P10 / P50 / P90** | 10th / 50th / 90th percentile of a Monte-Carlo output. |
| **Pareto frontier** | Candidates not beaten on every objective at once by another candidate. |
| **QT-xx** | Component qualification test (`09_VALIDATION/protocols/TEST_PLAN.md`). |
| **S-cell R0** | The salt-iron planar test cell designed here (CAD SB-SC-001). |
| **SCM-1** | Salt-cell test monitor PCB and firmware (`05_ELECTRONICS`). |
| **TQ** | Threshold quantity in NFPA 855 / IFC: above it, extra fire-code requirements apply. |
| **ZEBRA** | Na–NiCl₂ molten-salt battery ("Zero Emission Battery Research Activities"). |
