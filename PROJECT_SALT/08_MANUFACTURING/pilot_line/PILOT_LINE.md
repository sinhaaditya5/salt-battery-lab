# Stage B — Pilot line (only after G1–G5 pass). Concept: 10 MWh/yr scenario

**Do not build until the R0 gates pass.** The parameters below are untested scale-ups of the lab steps.

| Module | Lab step it scales | Pilot equipment (concept) | Key control | Traceability |
|---|---|---|---|---|
| Material handling | B-02 | Vacuum dryer 50 kg/batch; dry-room storage (dew point ≤ −40 °C) | KF moisture < 100 ppm | lot ID → cell ID |
| Mixing | B-03 | Low-shear powder mixer, inert gas | mass ±0.5 % | recipe version |
| Melt synthesis | B-04 | 10–20 kg NaAlCl₄ reactor with HCl scrubber | colour; melting point | batch |
| Granulation | B-05 | Roll compactor + mill + sieves | tap density 1.9 ± 0.1 g/cm³ | batch |
| Ceramic | C-01…C-03 | **Buy** discs and rings; glass-seal furnace (belt or batch) | He leak 100 % | disc serial |
| Assembly | D-03…D-06 | Semi-automatic stack press in a dry room; torque-controlled closure or laser weld | insulation > 100 MΩ; stack height | cell serial (2-D code) |
| Fill and seal | D-07/D-08 | Vacuum melt-filling station; laser seal of the fill tube | mass gain ±3 %; He leak | cell serial |
| Formation | F-01…F-03 | 50–100 heated channels (190–300 °C racks), cycler | first-charge capacity; ASR | cell data file |
| Inspection | G | EIS station; CT (sample) | ASR; OCV; dimensions | MES record |
